Lessons Outlive Their Failures

What a six-week study of this harness found, and what divan changed because of it.

Some lessons may no longer be needed, and stale documentation keeps coming back. A lesson is a rule or a check added after an agent mistake. On a current model, three of four replayed past failures did not happen even without their lesson. Stale documentation (drift) was the largest failure class: 48 of 118. One LLM audit found only about half of it.

So divan now gives every lesson a model and a re-test date, replays lessons to find the ones that can retire, and adds code checks where drift slipped through.

What it costs

  • The monthly audit: three runs and a merge, about $4 in API-equivalent tokens and 15 minutes.
  • A replay: in the study, 30 runs took 10 minutes and cost about $3.55. At 10 runs per condition, a set of five scenarios costs about $12.
  • Each new lesson: one register row and, for a check, two test cases.

What is not proven

  • Three runs per condition. A failure that did not happen in three runs can still happen.
  • One repository, one owner. Other harnesses can behave differently.
  • The replay keeps code checks even when the failure is gone: they cost nothing per session, and one still stopped an em-dash on an older model.
  • The heading check sees pointers written as `file.md`, "Heading". A pointer in plain words passes.
  • The identifier scan uses patterns only. A number with no label and no checksum passes.
  • Running the agent under libfaketime instead of shifting dates is offered but not verified.

Lesson
A rule or a check added after an agent made a mistake.
Drift
A statement in the docs that a later change made wrong.
Lint check
Code that refuses a commit when a pattern is found.
Replay
Running a past task again in a throwaway copy of the repository.
Condition A and B
The copy without the lesson (A) and with only the lesson added (B).
Recall
The share of known problems an audit finds.
Retire
Move a lesson to the archive with the replay result. Nothing is deleted.
